How to borrow: each shelf opens in Google Drive - download the volume you fancy, load it into AstroWizard, and follow the steps. Masters are big files (real data, real weight) - the size is on every ticket. On very busy days a volume can hit Drive’s daily download limit; if one won’t come down, try again tomorrow.

Why a library? Because the best part of this hobby - turning raw starlight into a picture you’re proud of - shouldn’t have to wait for clear skies, working gear, or a lottery win. Download a master, open it in AstroWizard (or any tool you like), and learn by doing. Every set will be free, forever.

The borrowing rules (plain English, like everything here): the data is free to learn from, and whatever you make from it is yours - post it, print it, enter it in competitions, show it off, all with the wizard’s blessing. A little credit (“data: The Wizard’s Library”) is always lovely but never required. The one ask: please don’t re-host or sell the data sets themselves - send fellow wizards here instead, so the Library stays one place, kept current and free.

Like everything the wizard builds, the Library is founded on, and maintained by, kindness.

The shelves are free, forever. But if the Library lends you the stars on a cloudy night and you fancy keeping the hearth lit, the coinpurse is by the door - and kindness is honoured back: your name in The Wizard’s Fellowship, for all time.
